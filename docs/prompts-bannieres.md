# Bannières panoramiques : textes pour générer les images

Chaque texte est complet : copie-le tel quel dans ton générateur d'images (une image par thème).
La version anglaise donne souvent de meilleurs résultats avec les générateurs.

Quand les images sont prêtes, dépose-les dans `fond_ecran/` avec ces noms (PNG ou JPG) :
`banniere_ninjas`, `banniere_ocean`, `banniere_plants`, `banniere_land`, `banniere_birds`, `banniere_ancient`, `banniere_modern`.
