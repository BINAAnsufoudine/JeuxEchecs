# Bannières panoramiques : textes pour générer les images

Chaque texte est complet : copie-le tel quel dans ton générateur d'images (une image par thème).
La version anglaise donne souvent de meilleurs résultats avec les générateurs.

Quand les images sont prêtes, dépose-les dans `fond_ecran/` avec ces noms (PNG ou JPG) :
`banniere_ninjas`, `banniere_ocean`, `banniere_plants`, `banniere_land`, `banniere_birds`, `banniere_ancient`, `banniere_modern`.

# Quatre nouveaux thèmes : bannières et vignettes

Bannière : format 3:1, sujet à droite, tiers gauche calme pour le texte de l'accueil.
Vignette : petite image du carrousel (240 × 146 dans l'appli). Le sujet doit se lire en tout petit : un seul sujet, centré, gros plan.

Noms de fichiers à déposer dans `fond_ecran/` : `banniere_auras`, `vignette_auras`, `banniere_sabres`, `vignette_sabres`, `banniere_baobabs`, `vignette_baobabs`, `banniere_dinos`, `vignette_dinos` (PNG ou JPG).
